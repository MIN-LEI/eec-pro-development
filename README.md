# eec-pro-development

Agent skill for EPLAN EEC Pro 2026: the mechatronic model and typicals
(variants, conditions), the formula language, configuration interfaces, Groovy
actions, C# post-generation scripts, the EOX model, and generation into Electric
P8, Pro Panel, PLC, Graph2D and Office, locally or via the Job Server.
